# Steam store brief — draft for review

Product: **Bonk Club**. Windows and Linux are intended launch platforms.
English is the current interface language. Steam App ID, publisher name, support
contact, price and release date are not selected.

## Short description

A 2D physics fighting game for up to four players online, with solo AI opponents.
Fight across destructible arenas using melee, guns and unusual weapons. Push
furniture, break floors and trigger connected fire, water, electricity and gas
reactions. The last fighter alive wins the round.

## Description facts

- Online rooms for up to four fighters, with invite codes, host-controlled slots
  and joining during play. Single player against AI.
- Physical movement, recoil, thrown weapons, moving cover and destructible terrain.
- 27 arenas across homes, hospitals, industry, jungle, desert, ice, volcanoes and
  skyscrapers. Check the arena count again against the submitted build.
- Custom names, colours, hairstyles and accessories. Continuous rounds and scores.
- Mouse/keyboard and gamepad gameplay, controller menu navigation and saved settings.
- Stylised stick-figure violence, blood, dismemberment and impalement.

Avoid using Stick Fight artwork, logos, music or implied affiliation. Do not list
local multiplayer/Remote Play Together, achievements, Steam Cloud, Steam friend
invites, full controller support or Deck Verified until implemented and verified.
Online play requires a network connection; solo play runs offline. The current
host leaving ends the room. Final store copy must match final transport behaviour.

## Assets to create from the accepted build

Use the existing original Bonk Club identity. Prepare a consistent capsule set,
library artwork, application/community icons, at least five clear gameplay
screenshots and a short gameplay trailer. Capture fights, readable destruction and
different arenas at the final shipping settings; do not present concept art as
gameplay. Show actual player movement/combat early in the trailer.

Download Valve's current templates when producing the final capsules. Current
store capsule sizes include header 920×430, small 462×174, main 1232×706 and vertical
748×896. Treat the linked specification as the authority if these change.
[Store graphical assets](https://partner.steamgames.com/doc/store/assets/standard)

Screenshots from the desktop smoke are QA evidence, not final store photography.
The executable icon is an export of the existing favicon; it is not a substitute
for the store capsule and library artwork. No third-party stock assets were added.

## Do not invent minimum requirements

Measure the release on an older integrated-GPU Windows machine and the Deck,
including four-player destruction and particle-heavy rounds. Record memory,
storage and host/guest frame times separately. Fill the requirements only after
those checks, with the supported OS/runtime versions. The build machine's specs
do not establish minimum requirements.
